# 📡 Радар IT-заказов

Агрегатор свежих IT-заказов для фрилансера из Казахстана. Каждые 20 минут он собирает
заказы с бирж, hh.kz и публичных Telegram-каналов, отсеивает спам, не-IT задачи
и рекламу исполнителей, склеивает дубли и делит заказы на
🔥 **горячие**, 🟡 **тёплые** и ❄️ **холодные**. Результат — сайт с лентой и фильтрами
и (по желанию) уведомления о горячих заказах в ваш Telegram.

Работает бесплатно на GitHub Actions + GitHub Pages, свой сервер не нужен.

## Источники

| Источник | Как собирается |
|---|---|
| Kwork (Разработка и IT) | JSON списка проектов |
| Хабр Фриланс, FL.ru, Freelancehunt, Weblancer | RSS |
| hh.kz (IT в Казахстане), hh — проектная удалёнка | официальный API hh |
| Freelancer.com | публичный API |
| Reddit r/forhire, We Work Remotely | RSS |
| Telegram-каналы | веб-превью `t.me/s/<канал>`, без ключей |

Площадки, которые нельзя собирать автоматически (Upwork, Fiverr, YouDo, Workzilla,
Profi.ru, Автор24, Studwork, Enbek.kz, OLX.kz, Госзакупки и др.), собраны в каталоге
на вкладке **«Площадки»**.

Статус каждого источника (работает / ошибка, сколько записей и сколько прошло фильтр)
показан на вкладке **«Источники»**. Если источник сломался, остальные продолжают работать.

## Как оценивается заказ

Оценка от 0 до 100 (правила в `aggregator/classify.py`, словари в `aggregator/keywords.py`):

- **свежесть**: до +30 (меньше 3 часов);
- **бюджет в ₸**: до +28, валюта пересчитывается по курсам из `config.yaml`;
- **проект «под ключ»**: +15 (приложение, MVP, платформа, маркетплейс, личный кабинет);
- **веб/мобайл/бэкенд/боты**: +8, фронт и бэк вместе ещё +4;
- **мало откликов**: +10, много откликов −8;
- **срочно** +5, **Казахстан** +6, **контакт в Telegram-посте** +4;
- **мелкие правки** −8.

🔥 60+ · 🟡 35+ · ❄️ остальное. Пороги задаются в `config.yaml`.

Для Telegram отдельный фильтр: сообщения вида «выполню», «ищу работу», `#резюме`
и сообщения без признаков заказа («нужен», «требуется», «бюджет», «ТЗ»…) отбрасываются.

## Запуск на GitHub (один раз)

1. **Сделайте репозиторий публичным** (Settings → General → Danger Zone). GitHub Pages
   для приватных репозиториев доступен только на платном тарифе.
2. Убедитесь, что код лежит в ветке по умолчанию (Settings → General → Default branch): расписание запускается только там.
3. **Actions → «Сбор заказов» → Run workflow**. Первый запуск создаст ветку `gh-pages`.
4. **Settings → Pages → Build and deployment → Deploy from a branch → `gh-pages` / `(root)`**.
   Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.
5. Дальше лента обновляется сама каждые 20 минут.

### Уведомления о горячих заказах в Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Напишите своему боту любое сообщение, откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": ...}`.
3. **Settings → Secrets and variables → Actions → New repository secret**:
   `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

Бот присылает только новые горячие заказы, не больше `notify_limit` за один прогон.

## Настройка

Всё основное настраивается в `config.yaml`:

- `telegram.channels` — список каналов. Добавьте свои, в том числе казахстанские и
  университетские чаты. Подходят только **публичные** каналы/группы с веб-превью.
  Проверить канал можно по ссылке `https://t.me/s/<канал>`: если сообщения видны, он подойдёт.
- `sources` — биржи. Источник можно выключить строкой `enabled: false`.
- `settings.thresholds` — пороги горячий/тёплый.
- `settings.rates_to_kzt` — курсы валют.
- `directory` — каталог площадок на сайте.

Список Telegram-каналов в конфиге стартовый, и не все из них могут существовать или
публиковать заказы. После первого прогона откройте вкладку «Источники» и уберите
каналы с ошибкой или с нулём в колонке «IT».

## Локальный запуск

```bash
pip install -r requirements.txt
python -m aggregator check             # проверить все источники, ничего не сохраняя
python -m aggregator run --no-notify   # собрать заказы в site/data/jobs.json
python -m aggregator run --only tg:    # только Telegram (regex по id источника)
python -m aggregator demo              # демо-данные, чтобы посмотреть сайт без сети
python -m aggregator serve             # сайт на http://localhost:8000
python -m pytest -q                    # тесты
```

## Структура

```
aggregator/
  sources/        парсеры: telegram, rss, kwork, hh, freelancer
  classify.py     фильтр (спам / не-IT / реклама исполнителя) и оценка
  keywords.py     словари ключевых слов, главный рычаг качества ленты
  budget.py       извлечение бюджета из текста и перевод в ₸
  pipeline.py     сбор → фильтр → оценка → дубли → jobs.json
  notify.py       уведомления в Telegram-бот
site/             статический сайт (index.html, app.js, styles.css)
config.yaml       источники, каналы, пороги, каталог площадок
.github/workflows сбор каждые 20 минут + тесты
```

## Идеи для развития

- Закрытые Telegram-чаты через Telethon (нужен ваш аккаунт и `api_id`/`api_hash`).
- Оценка «спорных» заказов через LLM.
- Шаблоны откликов для каждого типа заказа.
